# Forum Project

A Flask forum application project focused on categories, discussion threads, replies, authentication, and relational data modeling.

## Planned / current areas

- Categories and threads
- Posts and replies
- User authentication
- SQLite and SQLAlchemy
- Flask-WTF forms
- Database migrations

The roadmap in this README describes planned development and should not be read as a list of completed features.
